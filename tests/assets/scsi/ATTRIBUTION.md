# SCSI Test Assets

## scsi0.dat / scsi0.dsc

BeebEm ADFS-formatted SCSI hard disc image (9.7 MB) with sample files.
Used for existing C++ integration tests (test_scsi_adfs_boot, etc.).

## Blank ADFS images (BBCHDDs.zip)

Moved to `scripts/adfs-disc-tools/` as package data.
Use `adfs-disc-tools list-sizes` and `adfs-disc-tools create-image` to access.
